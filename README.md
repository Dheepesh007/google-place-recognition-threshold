# 📍 Google Place Recognition (Threshold-Based Matching)

## 🧠 Overview

This project demonstrates a simple place recognition technique used in robotic localization and mapping. It uses a **similarity score** and a **threshold value** to determine whether a place has been previously visited.

This concept is widely used in Google Maps and autonomous navigation systems.

---

## 🎯 Objective

To implement a threshold-based decision rule:

If similarity score > threshold → Place Recognized

---

## 📊 Dataset Used

* Oxford RobotCar Dataset
  🔗 https://robotcar-dataset.robots.ox.ac.uk

Used for real-world robotic localization and mapping.

---

## ⚙️ Implementation

* Language: Python
* Platform: Google Colab / VS Code
* Concept: Similarity Matching

---

## 🧮 Example

* Similarity Score = 0.94
* Threshold = 0.9

**Output:**
Place Recognized

---

## 🏭 Industry Application

Used in:

* Google Maps navigation
* Autonomous vehicles
* SLAM (Simultaneous Localization and Mapping)
